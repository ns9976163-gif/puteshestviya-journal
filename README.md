# Мои путешествия

Личный планировщик поездок и тревел-журнал. Сайт работает в браузере; поездки сохраняются локально, фотографии и документы — в IndexedDB. Данные пользователя не входят в этот репозиторий.

## GitHub Pages

После включения GitHub Pages с источником **GitHub Actions** сайт публикуется автоматически при каждом обновлении ветки `main`.

## Локальный запуск

Открой `index.html` в современном браузере. Для надёжной работы с вложениями удобно использовать локальный веб-сервер, например Live Server.
